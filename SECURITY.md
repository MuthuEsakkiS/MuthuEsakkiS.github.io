# Security Policy

This is a static personal portfolio site (Next.js, statically exported, hosted on GitHub
Pages). It has no backend, database, authentication, or server-side code, which
significantly limits its attack surface.

## Reporting a vulnerability

If you find a security issue with this site (e.g. a dependency vulnerability, an
exposed secret, or a misconfiguration), please open a private report via
[GitHub Security Advisories](../../security/advisories/new) for this repository,
or email **esakkimuthu.sivaraman@gmail.com** directly.

Please do not open a public issue for security-sensitive reports.

## Scope

- Source code and build configuration in this repository
- The deployed static site

Out of scope: GitHub Pages/GitHub Actions infrastructure itself (report those to GitHub).

## Supported versions

Only the `main` branch (the version currently deployed) is supported.
